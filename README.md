# Yogesh Sharma - AI/ML Portfolio

[![React](https://img.shields.io/badge/React-19.2-61DAFB?style=for-the-badge&logo=react&logoColor=black)](https://react.dev/)
[![Vite](https://img.shields.io/badge/Vite-8.0-646CFF?style=for-the-badge&logo=vite&logoColor=white)](https://vitejs.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg?style=for-the-badge)](LICENSE)

Modern, responsive personal portfolio website for Yogesh Sharma, focused on AI/ML, cloud computing, certifications, and project showcase.

## Features

- Fully responsive layout for mobile, tablet, and desktop
- Multi-theme UI with animated transitions
- Hero section with typewriter role effect
- About section with technical skills and profile summary
- Experience timeline
- Project cards with interactive tilt effects
- Certifications section
- Contact section with email/phone/location and quick CTA
- Downloadable resume integration

## Tech Stack

- React 19
- Vite 8
- JavaScript (ES6+)
- CSS3
- Lucide React icons

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Run Locally

```bash
git clone https://github.com/yogeshmehta18/Portfolio.git
cd Portfolio
npm install
npm run dev
```

App runs at: http://localhost:5173/

## Production Build

```bash
npm run build
npm run preview
```
